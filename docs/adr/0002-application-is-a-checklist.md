# An application is a checklist, not a filing

The real freshman process uses scans, registrar forms, and sometimes an essay, recommendations, a fee, or several ranked programs. We keep an application as the checklist for one university: the applicant ticks lines, and status is Not started, In progress, or Submitted. Submitted means every line is done in Kolehiyo Central, not that the university received it. Each application has one chosen program, and the UP page notes that the real UPCAT asks for two campuses and up to four programs each. The fee is a note on the university page.

# The demo is a class walkthrough of the Big Four

The proposal describes a six-month platform for many Metro Manila schools, with document uploads, a university portal, scholarships, and a pilot. For Eng for Professionals the class watches a demo and does not review the code, so we build one laptop walkthrough: Jordan Santos, already signed in, looking up freshman admission for the Big Four and tracking those applications. The Big Four are the University of the Philippines (Diliman programs only), Ateneo de Manila, De La Salle University Manila, and the University of Santo Tomas, shown on one annual calendar so their cycles can be compared. Uploads, payments, scholarships, transfers, automatic reminders, a confirmation slip, a phone layout, and staff review of files are out. Admin, if time remains, only edits an application period.
